# Acme writing guide

A short guide, written the way teams usually write them, used as the worked
example for the `from-guide` skill. The rules under `styles/Acme/` were
derived from it; each one links back to the section it enforces. The forms it
bans are in code spans, which Vale skips, so the guide passes its own rules.

## Words

### Sign in

Use "sign in" for the action and "sign-in" for the page. Don't use `log in`,
`login` or `log on`.

- Do: Sign in to your account.
- Don't: `Log in to your account.`

### Filler

Don't tell the reader a task is trivial. Avoid `simply`, `just`, `easy` and
`obviously`.

- Do: Run the installer.
- Don't: `Simply run the installer.`

### Email

Write "email", never `e-mail`.

## Sentences

Keep sentences to 30 words or fewer.

## Headings

Use sentence case. Don't end a heading with a period or a colon.

- Do: `## Install the agent`
- Don't: `## Install the agent.`

## Voice

Write for a busy reader. Be warm, and never condescending.
